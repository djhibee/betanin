# Full transitive lock, generated from the site-packages of the betanin
# container running in production.
#
# requirements-docker.txt pins what betanin's Dockerfile installs explicitly.
# This file pins everything else -- betanin's own pyproject.toml dependencies
# and the whole transitive closure beneath them, none of which carried a
# version specifier anywhere.
#
# That gap was not cosmetic. Building with only requirements-docker.txt pinned
# still moved, among others:
#
#   jellyfish   1.0.3  -> 1.2.1    string distance; feeds beets match scores
#   mediafile   0.12.0 -> 0.17.0   beets' tag reader/writer
#   confuse     2.0.1  -> 2.2.1    beets' config parser
#   numpy       1.26.2 -> 2.4.6    major version
#
# jellyfish in particular decides how close a candidate is, which decides
# whether an album lands above match.strong_rec_thresh -- i.e. whether it
# imports silently or stops to ask. Letting it float would have reproduced
# beets exactly and still changed matching behaviour.
#
# beets and beets-bpmanalyser are absent here on purpose: they are installed
# from pinned commit URLs in requirements-docker.txt, and a version constraint
# cannot be applied to a direct URL requirement.
#
# Regenerate deliberately, never automatically.
#
# Security bumps (2026-10), away from the production snapshot, for packages
# with published advisories and no part in beets matching: certifi, flask-cors,
# flask-socketio, h11, httpcore, idna, jinja2, pillow, pyjwt, python-engineio,
# python-socketio, requests, simple-websocket, urllib3, werkzeug.
#
# Python 3.14 bumps (alpine 3.24), the minimum needed for the pinned set to
# build or import on 3.14: gevent, greenlet, zope-interface (C extensions),
# sqlalchemy, typing-extensions (typing internals), rpds-py (segfaults),
# confuse 2.0.1 -> 2.1.0 (pkgutil.get_loader was removed; 2.1.0 is the first
# release without it, the rest of the diff is typing and py2 cleanup).
# standard-imghdr / -aifc / -sunau / -chunk and audioop-lts are verbatim
# backports of stdlib modules removed in 3.13, imported by mediafile 0.12.0
# and audioread 3.0.1; they keep those two pinned and byte-identical.
# See docs/FORK.md.
